## 1. Letter of Intent — template

> **Purpose for the assessor reading a signed LOI:** it evidences real demand
> from a named, checkable organisation. An LOI is not a contract and does not
> commit the provider to purchase; it records their intent to evaluate/pilot.

**METICLE CARE — LETTER OF INTENT (non-binding)**

- Provider name / CQC location ID (if registered): ___________
- Provider contact, role, date: ___________
- What the provider currently uses for rostering/records/compliance: ___________
- What they would pilot: ☐ rostering & visit verification ☐ four-nations
  compliance readiness ☐ family portal ☐ medication records ☐ full platform
- Scope: ___ locations, ___ staff, ___ service users (approx.)
- Pilot duration: 8 weeks (default) from onboarding completion
- What the provider contributes: a named manager as pilot sponsor; ~2 hrs/week
  feedback; real (or realistic-anonymised) service-user data
- What MeticleCare provides: onboarding, training, support, and pilot pricing
  credit (below)
- Success criteria (agreed up front, measured at week 8): see §2
- Non-binding statement: *"Signed to indicate intent to evaluate MeticleCare in
  a structured pilot. This letter is not a contract and creates no payment
  obligation."*
- Signatures and dates: ___________

**Rules for use:** never pre-sign a provider's name; never describe an LOI as a
contract; one signed copy → `docs/funding/signed/` (local only, not committed)
and a row in §4's pipeline; the endorsement file cites the count and the
providers' names **with their written permission only**.

## 2. Pilot design (default 8 weeks, NHS variant separate)

The D2A/NHS pilot is already designed in `docs/funding/nhs-pilot-proposal.html`
("Pilot Design", "Evidence & Evaluation Framework"). The default private-provider
pilot below reuses its evaluation discipline for the core segment:

| Week | Focus | Evidence produced |
|---|---|---|
| 0 | Onboarding, staff import, vetting records, framework selection (nation) | Setup log; baseline compliance score |
| 1–2 | Rostering + visit capture on live rounds | Visits created/completed counts |
| 3–4 | Daily notes, medication records, family portal invites | Records created; family activations |
| 5–6 | Compliance readiness: evidence pack export against the provider's nation's framework | Readiness score Δ from baseline |
| 7 | Carer + manager feedback interviews (structured, recorded with consent) | Verbatim feedback file |
| 8 | Success-criteria review; convert / extend / close decision | Signed pilot review (template below) |

**Success criteria (agree per-provider at week 0, measure at week 8):**
admin hours/week saved (manager's own estimate, before vs after); % visits with
complete digital records; readiness score improvement; family-portal
activation rate; would-they-recommend (0–10).

**Pilot review (one page, week 8):** criteria table with measured results, the
provider's own words (quoted with permission), and one of three outcomes:
**convert** to paid (on which tier), **extend** (why, new end date), **close**
(what we learned — a closed pilot with written findings is still evidence of
structured planning).

## 3. Outreach plan (owner: Adetoye, starting this week)

**Targets by segment** (from `INNF_8.3d_MARKET_RESEARCH.md` §3): 30 agencies in
weeks 1–4 — 20 single-site (Starter tier fit), 7 small-group (Professional), 3
multi-branch four-nations operators (Enterprise). Wales/Scotland/NI agencies
included deliberately: the four-nations demo is the differentiator.

**Weekly cadence:** 10 tailored outreach emails (per-nation compliance angle
where relevant, location-privacy angle where the provider employs carers they
struggle to retain — see `POSITIONING_LOCATION_PRIVACY.md` for the
objection-handling), 5 follow-up calls, 2 demos. Log every touch in §4.

**The ask, in order:** demo → pilot agreement (§2, priced credit) → 8-week
pilot → LOI or conversion. An LOI **before** a pilot is acceptable when the
provider wants to defer the pilot to a funding-linked start date; the LOI then
names the intended pilot window.

**Review:** weekly self-review against §4; if 2 consecutive weeks produce <3
demos, change the message, not the volume.

## 5. What "good" looks like at each checkpoint

- **+4 weeks:** 30 agencies contacted, ≥8 demos, ≥2 pilot agreements signed.
- **+8 weeks:** 1–2 pilots running, ≥1 LOI signed.
- **+12 weeks:** 2 pilots running or completed, ≥3 LOIs, ≥1 conversion
  negotiation — the funding ask's traction slide then shows dates and counts,
  not intentions.
- Any checkpoint missed → the weekly review decides: message change, segment
  change, or effort change, recorded in §4's notes. A missed checkpoint recorded
  and responded to is still structured planning; a missed checkpoint hidden is not.
