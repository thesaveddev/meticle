# Landing page surface brief

## Scope and mode
- Target: `/` (apps/web/src/pages/LandingPage.tsx). Mode: **Persuade** — the visitor decides and acts.
- The marketing chrome around it (NavHeader, MarketingLayout footer) is part of this surface's world.

## Audience, job, action
- Audience: registered managers, owners and operations leads of UK supported living and domiciliary care providers.
- Job: believe the whole working day (rota, medication, notes, compliance) can be run from one connected platform.
- Action: start a free trial (register) or explore How It Works / the features tour.

## Proof / content
- Proof is the product itself: the live dashboard seated in a framed window, plus five real connected workflows. No invented stats, testimonials, logos, or scores. Every claim is real (AES-256, audit trail, five CQC domains from live records, four UK regulators, DSPT ten standards, KLOE evidence packs, 14-day no-card trial).
- Constraints: keep the existing routes and page functionality; only real project imagery (meticle_dashboard_hero.jpg).

## Chosen direction
- Brief-pinned editorial-operations world: deep navy #0F4C81 + single emerald #10B981 accent, warm bone grounds, charcoal ink, Inter, editorial hairlines, framed product windows on warm surfaces, one authored hero entrance, reduced-motion respected.
- Memorable moment: the dashboard window with the "Care note recorded" toast, seated on the hero.
